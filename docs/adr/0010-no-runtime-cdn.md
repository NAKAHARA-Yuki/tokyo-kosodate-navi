# ADR 0010: フロントエンドの依存を CDN から読まずリポジトリに取り込む

- ステータス: 採用
- 日付: 2026-08-01

## 背景

画面の描画は cytoscape.js に全面的に依存しているが、これを実行時に CDN から読んでいた。

```html
<script src="https://unpkg.com/cytoscape@3.29.2/dist/cytoscape.min.js"></script>
```

これがエージェントコンテナ（[ADR 0009](0009-agent-container.md)）で E2E を壊していた。
コンテナは外向き通信を許可リストに絞っており、`unpkg.com` が入っていない。
iptables は REJECT ではなく DROP なので即エラーにならず、ブラウザは黙って待ち続ける。

症状の分かりにくさが問題だった。

```
RESP: 200 http://127.0.0.1:47781/     ← HTML 自体は取得できている
RESULT FAILED                          ← なのに goto はタイムアウト
```

HTML は 200 で返る。落ちるのは `page.goto` が `waitUntil="load"` で全サブリソースを待つためで、
cytoscape.js が取れず `load` が発火しない。エラーメッセージは「タイムアウト」としか言わないので、
Chromium やサンドボックスの制約に見えてしまう。実際そう誤診された。

結果として**コンテナ内では E2E が一度も通っていなかった**。CI（GitHub Actions）は
外向き通信が自由なので緑のままで、環境差に気づく機会も無かった。
フロントを触る変更をコンテナ内の Claude Code が自己検証できない状態が続いていた。

## 決定

**ブラウザが実行時に読むものを外部ホストから取らない。必要なライブラリは
`app/static/` に取り込んで自分で配る。**

- 版・取得元・sha256 を `app/static/README.md` に記録する
- 版を上げたら記録も更新し、`make e2e` を通す

ファイアウォールに `unpkg.com` を追加する案は採らなかった。

## 理由

### 本番の依存の扱いと矛盾していた

[ADR 0007](0007-dependency-locking.md) で、本番イメージの Python 依存は推移依存まで
ハッシュ付きで固定すると決めている。「本番に何が入っているかを特定できること」が目的だった。

一方でフロントエンドは、第三者のホストがその時返したものを無検証で実行していた。
サーバ側で防いだのと同じ種類のリスクが、ブラウザ側に素通しで残っていたことになる。
公開されている行政サービスとして、これは通らない。

### 許可リストに穴を開けるのが高くつく

> 補足（2026-08-01）: この節が根拠にしている許可リストは
> [ADR 0011](0011-drop-egress-allowlist.md) で撤回した。
> したがってこの理由は現在は成り立たない。
> **上の「本番の依存の扱いと矛盾していた」だけで本 ADR の決定は維持される。**

unpkg は Cloudflare に載っている。解決した IP を許可すると Cloudflare 配下の広い範囲が通る。
ファイアウォールは「承認なしで何でも実行できる状態で、プロンプトインジェクションによる
データ持ち出しを止める層」として置いたものなので、そこに広い穴を開けると意味が薄れる。

E2E を通すために本番のセキュリティ姿勢と隔離の実効性を両方下げることになり、割に合わない。

### 副次的に環境差が消える

CI・コンテナ・ローカル・Cloud Run のどこでも同じものが読まれる。
unpkg の障害やレスポンス遅延で画面が描画されない事故も無くなる。

## 帰結

- コンテナ内で `make e2e` が通るようになり、フロントの変更を自己検証できる
- リポジトリに 372KB のミニファイ済み JS が入る
- 版の追従が手動になる。`app/static/README.md` に手順を書いて放置を防ぐ
- 今後フロントにライブラリを足すときは、CDN の script タグを書かず取り込む

## 積み残し

取り込んだファイルが記録どおりのものか検証する仕組みは無い。
sha256 は README に書いてあるだけで、CI では照合していない。
数が増えるようなら照合を `make check` に足す。

## 追記（2026-08-01）: 配置場所を `frontend/public/` に移した

issue #33 で画面を Next.js（`frontend/`）に移し、backend から HTML 応答を無くしたため、
`app/static/cytoscape.min.js` を `frontend/public/cytoscape.min.js` に移設した。
版と sha256 の記録先も `frontend/public/README.md` に移している（内容と手順は同じ）。

**方針そのものは変わっていない。** ブラウザが実行時に読むものは外部ホストから取らず、
リポジトリに取り込んで自分で配る。
