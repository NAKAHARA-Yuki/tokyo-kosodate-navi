# 就労要件はどう書かれているか（issue #126 の実測）

計測: `scripts/survey_employment_conditions.py`（dev, 7,812件に対して実行）
日付: 2026-08-18

## 結論を先に

**持つべきなのは「就労状況」ではなく「保育の必要性の事由」。**

条件文が聞いているのは「働いていますか」ではなく
**「保育を必要とする事由に当てはまりますか」**で、就労はその9事由のうちの1つでしかない。
就労だけを属性として持つと、**残り8事由で対象になる人を取りこぼす。**

```
就労の語を含む 336件（55スキーム）
  265件（78.9%）が 保育・学童系      ← 保育の必要性の認定の話
   71件            ひとり親の就業支援  ← 「就労しているか」ではなく「就職を目指しているか」
```

## 1. 条件は「保育の必要性の9事由」

子ども・子育て支援法施行規則の標準事由が、そのまま条件文に並んでいる。

| 事由 | 本文に出る件数 |
|---|---:|
| 就労 | 198 |
| 疾病・障害 | 158 |
| 就学 | 123 |
| 介護・看護 | 107 |
| 妊娠・出産 | 93 |
| 求職活動 | 67 |
| 災害復旧 | 62 |
| 育児休業 | 35 |
| 虐待・DV | 18 |

典型的な書き方はこう。

```
保護者の就労や疾病等により、家庭において保育を受けることが困難な児童
・保護者が、就労を必要とするとき
・保護者が、就労のための技能を習得するとき
【求職活動】児童の保護者が求職活動をしている場合
```

**「就労状況（就労中／求職中／就学中／育休中）」という属性は、この9事由の一部を
別の名前で切り出したものにすぎない。** 事由そのものを持つほうが素直で、取りこぼしも少ない。

### すでに持っている属性と重なる

- **妊娠・出産（93件）** → `is_prenatal` がある
- **疾病・障害（158件）** → `has_disability` がある。ただし**いまの `has_disability` は子どもの障害**で、
  ここでいうのは**保護者の**疾病・障害。**主体が違う**ので、そのままは使えない

## 2. 就労時間のしきい値は 50件。値は収束している

数値が本文にあるものは 50件（14.9%）で、**書き方は数えられる程度しかない。**

| しきい値 | 件数 |
|---|---:|
| 週3日以上 | 25 |
| 月48時間以上 | 20 |
| 1日4時間以上 | 17 |
| 月12日以上 | 16 |
| 月10日以上 | 4 |
| 週12時間以上 | 3 |
| 週5日以上 | 3 |
| その他（月64時間・1日6時間・週1日） | 5 |

`月48時間` は国が定める下限で、自治体はそれ以上を独自に設定している。

**単位が揃っていない。**「時間」と「日」、「月」「週」「1日」が混在するので、
属性として持つなら **月あたりの就労時間と就労日数の両方**が要る
（`週3日以上` と `月48時間以上` は換算できない。週3日×4時間＝月48時間で偶然一致するだけ）。

抽出そのものは正規表現で足りる。`age_rules.py` と同じ方式で書ける。

## 3. 保育系でない 71件は別の話

ひとり親の就業支援が中心で、**「いま働いているか」ではなく「就職を目指しているか」**を聞いている。

```
[高等職業訓練促進給付金]
  就業（仕事）または育児と修業との両立が困難であると認められる方
  当該事業と趣旨を同じくする給付（求職者支援制度における職業訓練受講給付金…）を受給していない方

[母子家庭及び父子家庭 自立支援教育訓練給付金]
  児童扶養手当を受けている方、または同等の所得水準にある方
  就職に結びつけるために当該講座が必要であると認められる方
```

2つ目は **#124（他制度の受給を条件とする関係）** そのもので、就労の属性では判定できない。
これらは「就労状況」ではなく **意向**（就職したい・資格を取りたい）で、
マイナポータルから取れる情報でもない。

## 4. 所得との重なりは小さい

```
所得の語も含む   54件 / 336件（16.1%）
```

issue #126 が「291件（84%）は所得条件を含まない」としていたのと同じ傾向で、
**#76 とはほとんど重ならない独立した要件**という見立ては正しい。

## 5. どうするか

**#126 は「就労状況を持つ」から「保育の必要性の事由を持つ」に読み替えるのがよい。**

1. **属性は9事由の多肢選択**にする（就労／疾病・障害／就学／介護・看護／妊娠・出産／
   求職活動／災害復旧／育児休業／虐待・DV）。就労だけを持たない
2. **就労時間のしきい値（50件）は規則で抽出できる。** ただし月あたりの時間と日数を
   別々に持つ必要がある
3. **保育系でない 71件は #126 から外す。** ひとり親の就業支援は意向の話で、
   #124（他制度の受給）と一緒に扱うほうが近い
4. `has_disability` は**子どもの障害**なので、**保護者の疾病・障害は別に持つ**必要がある

### マイナンバー準拠かどうか（#78 のスコープ判断）

#126 は「就労状況は住民票のように直接は載っていないため、
どこまでをマイナンバー準拠とみなすかは要検討」としている。

**保育の必要性の事由に読み替えると、この論点は消えない。** 9事由のうち
マイナポータルで取れる範囲にあるのは妊娠・出産（母子保健）と疾病・障害程度で、
**就労・求職・介護は自己申告**になる。属性の出どころが混ざることは #78 で決める必要がある。
